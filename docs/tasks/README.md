# Tasks

Name a task file `T-001-short-slug.md`. Copy `docs/tasks/_template.md`.

Active work sits in `docs/tasks/active/`. When the task is done, move the file to `docs/history/tasks/`. Tick every exit-criteria checkbox before the move. A task is not done until the domain docs it lists are updated, and `docs/reference/09-conventions-and-invariants.md` if an invariant changed.
